# Tasks

- Active `T-*.md` files live directly in this directory.
- Accepted, settled tasks move to `done/`.
- Deferred or intentionally stopped tasks move to `parked/`.
- `_state.yaml` is generated from Task-Spec frontmatter; never edit it by hand.
- `_metrics.jsonl` is an append-only lifecycle event index.

A task may enter `done/` only after it is signed, accepted, and backed by a
passing execution receipt. Historical Task-Specs remain immutable evidence.
